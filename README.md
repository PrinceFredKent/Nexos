# Nexos Health AI

Nexos is a premium, AI-driven Health Assistant designed for a seamless, offline-first medical experience.

## 🚀 Quick Start

### Prerequisites
- Node.js & npm
- Python 3.9+

### Installation

1. **Backend Setup**
   ```bash
   cd backend
   pip install -r requirements.txt
   # Setup .env (see DOCUMENTATION.md for details)
   python main.py
   ```

2. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

## ✨ Key Features
- **Symptom Analysis**: AI-powered health insights and risk assessment.
- **Cycle Tracker**: Elite glassmorphic period and cycle tracking.
- **Medication Manager**: Inventory and intake tracking with smart reminders.
- **Emergency SOS**: Rapid-access emergency services integration.
- **Offline Sync**: Hybrid SQLite/Supabase synchronization architecture.
